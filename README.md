# Amazing RP Overlay

Законы Amazing Online, парсер форума, ИИ и TXT-блокнот. Два игровых клиента:
ASI/DLL внутри игры и внешний оверлей; общий Python-бэкенд и менеджер источников.

**Автор: Vladislav_Shetkov.** AmazingHelper 2.8.0: пользовательский запуск — `AmazingHelper.exe`.
Установщик для всех пользователей — `AmazingHelperSetup.exe`; portable ZIP также доступен.
Из исходников графический лаунчер по-прежнему запускается через `start.bat`.
Управление базой (источники, обновление, диагностика) и настройки (оформление,
клавиши, ИИ/API) открываются внутри этого же окна. Карточки заметок и сборки
находятся на обзоре. Команда `manager --page appearance` также открывает
соответствующую вкладку лаунчера; повторный запуск использует существующее окно.

## Готовая программа

Скачайте установщик `AmazingHelperSetup.exe` или portable ZIP из GitHub Releases.
Также можно скачать **всю папку Release**, включая `_internal` и `licenses`,
и запустить `AmazingHelper.exe`. Python устанавливать не требуется. [Инструкция](docs/RELEASE.md).
Для обновления загруженного ASI/DLL требуется полный перезапуск игры.

## Папки

| Папка | Содержимое |

| `amazing_overlay` | Бэкенд, парсер, лаунчер, менеджер и внешний клиент |

| `.cache`, `.venv` | Кэши, промежуточные сборки, окружение Python |

## Разработка

Первичная подготовка: `scripts/run/run_manager.bat`. Все зависимости — в
`requirements.txt`. Основные команды: `python -m amazing_overlay launcher`,
`manager`, `overlay`, `backend`; парсер — `python -m amazing_overlay.cli`.
`scripts/build/build_native.bat` собирает ASI/DLL; `build_portable.bat` из той же
папки собирает весь комплект, проверяет его и обновляет Release с manifest.

Рабочая база, настройки, ключи и профиль форума находятся в
`%LOCALAPPDATA%\AmazingLawOverlay\v2`. Прежние законы, конфиг и ссылки перенесены
в `local`, импорт старых корневых файлов также поддерживается. Корневой `.env`
сохраняет совместимость. Восстановить таблицы из старых TXT нельзя: обновите источники.
