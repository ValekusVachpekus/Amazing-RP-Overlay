# Примеры источников

`urls.txt` — перенесённый из прежней версии публичный список тем форума.
Он служит отправной точкой: отдельные темы могли быть переименованы или заменены.

В окне управления откройте «Источники» → импорт `urls.txt` и выберите этот файл.
Перед обновлением проверьте нужные темы через предпросмотр.

Из исходников можно также скопировать файл в корень как `urls.txt` до первого
запуска бэкенда либо передать его явно:

```powershell
.\.venv\Scripts\python.exe -m amazing_overlay.cli --urls examples/urls.txt --export laws
```

Корневой `urls.txt` — рабочий файл пользователя, он не коммитится.
Скачанные документы и cookies в примеры не входят.
