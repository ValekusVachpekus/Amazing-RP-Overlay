# Amazing Law Overlay — готовый комплект

Скачайте репозиторий через **Code → Download ZIP** и распакуйте его. Для запуска
сохраните **всю папку `Release`**, включая `_internal` и `licenses`.
Python, Qt и инструменты сборки устанавливать не требуется. Система: Windows x64;
игровой модуль DLL/ASI — x86, Direct3D 9.

## Первый запуск

1. Запустите `start.bat`: откроется лаунчер. Выберите «Управление и парсер».
   Бэкенд запускается автоматически и продолжает работать после закрытия окна.
2. Во вкладке «Обновление» нажмите «Установить Chromium» или запустите
   `start_install-browser.bat`. Для первой установки требуется интернет.
3. Во вкладке «Источники» добавьте ссылки на темы форума или импортируйте свой
   `urls.txt`, затем обновите включённые источники. База законов в комплект не включена.
4. Настройте API, модель и ключ во вкладке «ИИ» и проверьте соединение.
5. Выберите один игровой интерфейс из вариантов ниже.

В лаунчере можно запускать и останавливать бэкенд, открывать папку базы законов
(`laws.db`) и папку заметок. Остановка отменяет фоновые задачи и дожидается
завершения уже принятых записей. Закрытие лаунчера оставляет бэкенд работающим.
В версии 2.4.1 лаунчер оформлен по Obsidian-прототипу. Пункты «Заметки» и
«Разработка» прокручивают обзор; «Настройки» открывает оформление в менеджере,
включая уже открытое окно. После обновления перезапустите старые окна программы.
Команды разработки показываются только при запуске из исходного проекта.
В управлении страницы выбираются слева; ширина колонок источников изменяется
независимо и сохраняется. Для TXT/JSON используйте экспорт на странице «Обновление».

## ASI / DLL

В версии 2.4 игровой интерфейс оформлен по Obsidian-прототипу: личное избранное,
графитовые панели, фиолетовые акценты, отдельные страницы оформления, хоткеев и API.
Звезда закрепляет закон, значок библиотеки сворачивает список. Стрелки у поиска
листают совпадения; ИИ открывается справа. Кнопка разворачивания находится рядом
с крестиком в шапке. «Перечитать базу» загружает изменения локальной базы без сети.

Запустите `start_backend.bat` (либо менеджер) и загрузите **один** файл:
`AmazingLawClient.dll` или `AmazingLawClient.asi`. Это два имени одного модуля;
одновременно загружать оба не нужно. Инжектора и ASI-загрузчика в комплекте нет.
Используйте уже настроенный совместимый способ загрузки.

- `Ctrl+L` — открыть в просмотре / скрыть.
- `Alt+F` — включить / выключить ввод и мышь интерфейса.
- `Esc` — ввод → просмотр → скрыть.
- `Alt+← / →` — предыдущий / следующий закон; `Alt+↑ / ↓` — прокрутка.
- `F3 / Shift+F3` — следующее / предыдущее совпадение поиска.
- Вкладка «Настройки» — прозрачность всего окна, общий размер шрифта, тема,
  анимация появления за 0,2 с и настройки API. После изменения нажмите «Сохранить».

После сворачивания игры или Alt+Tab панель остаётся скрытой до `Ctrl+L`.
Для обновления DLL/ASI полностью завершите игру и загрузите новый файл при следующем запуске.
Проверки внутри реальной игры описаны в [приёмке](docs/GAME_ACCEPTANCE.md).

## Внешний оверлей

Запустите `start_overlay.bat`. Бэкенд запускается автоматически.
Игра должна работать в оконном режиме без рамки. Сочетания `Ctrl+L`, `Alt+F`
и `Esc` управляют просмотром и вводом. При вводе возможен временный АФК.
Используйте один клиент, чтобы их горячие клавиши не конфликтовали.

## Данные и обновление

Настройки, ключи, законы и профиль форума находятся в
`%LOCALAPPDATA%\AmazingLawOverlay\v2`. Chromium — в `%LOCALAPPDATA%\ms-playwright`.
Эти данные сохраняются отдельно от комплекта и не публикуются в Git.
На новом компьютере нужно добавить источники и собственный API-ключ.

Перед переходом на новый комплект закройте старый менеджер и внешний оверлей,
завершите старый `AmazingLawOverlay.exe backend` через диспетчер задач,
полностью закройте игру. Затем запустите менеджер из новой папки и новую DLL/ASI.
Старый бэкенд не сможет сохранить новые настройки ASI.

`manifest.json` содержит SHA256 и размер каждого файла. Его проверяет команда
из исходного проекта: `.venv\Scripts\python.exe scripts\publish_release.py --check`.
Сборка и обновление этой папки: `scripts/build/build_portable.bat` в корне проекта.
Исходники находятся рядом с `Release`, повторно копировать их внутрь не требуется.

Подробности: [руководство v2](docs/V2.md), [локальный API](docs/PROTOCOL.md).

## Блокнот

`Ctrl+N` открывает блокнот; внутри редактора создаёт заметку. `Ctrl+S` — сохранить,
`Ctrl+F` и `F3` — поиск. Автосохранение через секунду. Папка Notes рядом с программой
не входит в дистрибутив и сохраняется при обновлении. Путь меняется в лаунчере,
менеджере или ASI. [Полная инструкция и восстановление](docs/NOTEBOOK.md).
