# AmazingHelper 2.8.0

Windows 10 1809+/11 x64. Python и инструменты сборки игроку не нужны.

## Установка и запуск

1. Скачайте `AmazingHelperSetup.exe` из GitHub Releases. Установщик запросит UAC
   и установит программу для всех пользователей. Запускайте ярлык AmazingHelper.
2. Для portable распакуйте весь `AmazingHelper-2.8.0-portable-x64.zip`, сохранив
   `_internal` и `licenses`, и откройте `AmazingHelper.exe`.
3. Откройте управление базой, установите Chromium существующей кнопкой, добавьте
   свои источники форума и настройки API. Законы и ключи в поставку не входят.
4. Запустите игру и нажмите **«Запустить»** в карточке внутриигрового ASI/DLL.
   При нескольких процессах выберите нужный. Если игры нет, запустите её и
   повторите нажатие. Открытие лаунчера само по себе DLL не загружает.

Extreme Injector для этого сценария не требуется. В комплект входит собственный
x86-помощник на Blackbone, загружающий только AmazingLawClient.dll через Manual Map.
DLL и ASI — два имени одного модуля; не загружайте оба. Ранее загруженный модуль
требует полного перезапуска игры при обновлении. Автоматический обход защиты
отсутствует; отказ доступа отображается как ошибка.

**Совместимость с реальной игрой и её защитой пока не подтверждена.**
Проверки собственного D3D9-host не подтверждают игровой ввод или отсутствие АФК.

## Управление

- Ctrl+L — просмотр/скрытие; Alt+F — ввод; Esc — ввод → просмотр → скрытие.
- Ctrl+N — блокнот; Ctrl+S — сохранить. После Alt+Tab оверлей остаётся скрытым.
- Внешний оверлей остаётся доступен отдельной кнопкой. Используйте один клиент.
- Закрытие лаунчера сохраняет работающий бэкенд; его остановка — штатной кнопкой.

## Данные и обновления

Настройки, API-ключи, база, история и профиль браузера находятся в
`%LOCALAPPDATA%\AmazingLawOverlay\v2`. Chromium — в пользовательском кеше
Playwright. Новая установленная версия предлагает выбрать прежнюю Notes либо
создать её в системной папке «Документы\AmazingHelper\Notes». Сохранённый ранее
путь имеет приоритет. Файлы автоматически не перемещаются.

Portable хранит Notes рядом с EXE; запуск из исходного проекта — в его корне.
Выбранную папку можно изменить в настройках. Кодировка и переводы строк
существующих TXT сохраняются; заметки не отправляются ИИ автоматически.

Лаунчер проверяет GitHub Releases в фоне. Установленная версия скачивает и
проверяет подписанное обновление по кнопке, штатно закрывает клиенты и бэкенд,
затем запускает Setup с UAC. Игру закройте самостоятельно. Portable открывает
ссылку на новый ZIP; заменяйте комплект после закрытия приложения и игры,
сохраняя Notes. Удаление установленной программы сохраняет личные данные.

Если установка была прервана, повторно запустите тот же Setup для восстановления.
У AmazingHelper пока нет Authenticode-сертификата; автообновления проверяются
отдельной подписью Ed25519 и SHA-256.
